# Churn-Modeling-with-XAI
A deep learning-based web application that predicts customer churn and explains the prediction using Explainable AI (SHAP).

## Overview
This project uses an Artificial Neural Network (ANN) to predict whether a customer is likely to churn.
Along with prediction, the app provides feature-level explanations showing why the model made a decision.

## Features
- Customer churn prediction using ANN (TensorFlow/Keras)
- Probability score for churn
- Explainable AI using SHAP
- Feature impact visualization
- Interactive UI built with Streamlit

## Tech Stack
- Python
- TensorFlow / Keras
- Scikit-learn
- Streamlit
- SHAP (Explainable AI)
- Pandas, NumPy
